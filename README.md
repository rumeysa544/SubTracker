# Subscription and Invoice Tracking System (SubTracker)

Bu proje, C# ve Windows Forms (Form Applications) kullanılarak geliştirilmiş bir Abonelik ve Fatura Takip Sistemi dönem ödevidir.

## Projeyi Yerelde Çalıştırma Adımları

1. Projeyi GitHub üzerinden indirin (Clone veya Download ZIP)
2. Proje ana klasörünü VS Code veya Visual Studio ile açın.
3. Editörün terminalini (Terminal > New Terminal) açarak sırasıyla şu komutları çalıştırın:

dotnet clean
dotnet run
